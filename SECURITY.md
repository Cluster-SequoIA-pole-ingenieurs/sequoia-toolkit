# Politique de sécurité

## Versions maintenues

Seule la dernière version publiée (dernier tag `vX.Y.Z`) reçoit des correctifs
de sécurité.

## Signaler une vulnérabilité

**Ne pas ouvrir d'issue publique.** Utiliser plutôt l'un de ces canaux privés :

- le formulaire « Report a vulnerability » de l'onglet
  [Security](https://github.com/Cluster-SequoIA-pole-ingenieurs/sequoia-toolkit/security)
  du dépôt ;
- un courriel à sequoia-ingenierie@univ-rennes.fr.

Indiquer la version concernée, l'ordonnanceur (Slurm, PBS Pro/OpenPBS, Torque)
s'il y a lieu, et les étapes permettant de reproduire le problème.

Nous accusons réception sous 5 jours ouvrés et tenons la personne informée
jusqu'à la publication d'un correctif.
